## 📚 O que eu aprendi

Este projeto me ajudou a praticar a criação de uma página responsiva a partir de um design de referência.

Durante o desenvolvimento, pratiquei o uso de elementos semânticos do HTML, a organização de conteúdos com seções e listas, a estilização de tabelas, o uso de fontes e cores personalizadas e a adaptação do layout para diferentes tamanhos de tela.

## 🚀 Próximos passos

Quero continuar aprimorando minha atenção aos detalhes ao reproduzir designs e praticando a criação de layouts responsivos com HTML e CSS.
